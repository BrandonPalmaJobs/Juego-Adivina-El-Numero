# Carril Rápido

PWA que detecta coches por carril (COCO-SSD / TensorFlow.js, todo en el navegador) y dice qué carril avanza más rápido.

- `index.html`: detección real con un video o con la cámara (más el GPS).
- `sim.html`: simulación de Blvd. de la Madrid (modo tablero y cámara fija).

Despliegue: importar el repo en Vercel; es un sitio estático, no lleva build.
